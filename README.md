Разработка велась "на скорую руку", реализовано за несколько недель.
Приложение дает возможность создать тест: как оценочный, так и в виде опроса и назначить готовые тесты на необходимых сотрудников или группы сотрудников. Есть возможность импортировать сотрудников и тесты из CSV. Сотрудник может пройти тест, а администратор может увидеть результат прохождения.
